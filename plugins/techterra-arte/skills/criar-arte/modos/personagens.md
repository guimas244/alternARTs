# Modo: Personagens e NPCs (rosto + corpo)

> **Em construção — fluxo completo na E4.** Até lá, use este resumo para orientar o usuário e não improvise scripts.

- **Entra:** o tema do lote (roster) ou o personagem a atualizar.
- **Sai:** `prompts/pagina_NNN.txt` (preâmbulo + bloco das 3 pessoas) → `PROMPT_IMAGEM_<A..D>.md` → páginas → rosto + corpo (tamanhos em [../regras/formatos.md](../regras/formatos.md)).
- **Anexos (ordem fixa):** estilo_pagina_1, prisions, beleza_marta, beleza_elira.
- **Regras:** [../regras/npc-personagens.md](../regras/npc-personagens.md). Centrais (método Lote 09): preâmbulo BEAUTY / WOMEN / EYES / FASHION / LAYOUT; página = 2 mulheres + 1 homem; mulheres femininas, meigas, sensuais com elegância (nunca "machonas"); todos adultos, sem nudez, lingerie, transparência ou pose vulgar; a magia é das criaturas (nada de aura, runa ou tatuagem luminosa na pessoa; só a prision brilha); nome escrito à mão e conferido (lista de nomes existentes: o usuário fornece); nenhum número além da idade no texto de cada pessoa (o preâmbulo mantém as coordenadas aprovadas).
- **Atualizar personagem de jogador:** fluxo próprio com a arte atual como referência ("DNA do rosto" + 2 âncoras); o rosto e o corpo atuais o usuário fornece.
